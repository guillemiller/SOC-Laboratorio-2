# SOC Laboratory 2 – Windows Security Event Investigation

## Descripción

Proyecto práctico de ciberseguridad orientado a simular tareas iniciales de un **SOC Analyst L1** mediante el análisis de registros de seguridad de Windows utilizando Python.

El laboratorio permite identificar actividades sospechosas, correlacionar eventos y generar alertas e informes de investigación.

## Objetivos

- Analizar eventos de seguridad de Windows.
- Identificar intentos de autenticación sospechosos.
- Detectar creación de cuentas y asignación de privilegios administrativos.
- Identificar ejecución de comandos PowerShell codificados.
- Correlacionar eventos por usuario y tiempo.
- Generar alertas e informes automáticamente con Python.

## Tecnologías utilizadas

- Python
- Windows Event IDs
- CSV
- Visual Studio Code

## Resultados

- 19 eventos analizados.
- 6 hallazgos identificados durante la investigación.
- 11 alertas individuales generadas.
- Informe de investigación y archivo de alertas exportados automáticamente.

## Estructura del proyecto

La carpeta `SOC-Laboratorio-2/` contiene los registros utilizados, el script de análisis y los resultados generados.

Este laboratorio utiliza registros sintéticos con fines educativos. Las detecciones se basan en reglas heurísticas y no representan una confirmación de compromiso real.
